# First Conditional

## Что изучаем

**First Conditional** — условные предложения для реальных или возможных ситуаций в будущем.

Главная идея:

- условие может реально случиться;
- результат относится к будущему;
- после **if** используем **Present Simple**, а в главной части часто используем **will + V1**.

Примеры:

- If it rains tomorrow, we will stay at home.  
  Если завтра пойдёт дождь, мы останемся дома.
- I will call you if I finish work early.  
  Я позвоню тебе, если закончу работу рано.

## Правило кратко

Формула:

**If + Present Simple, will + V1**

или

**will + V1 + if + Present Simple**

Примеры:

- If she studies, she will pass the exam.
- We will go for a walk if the weather is good.
- If I have time, I will help you.

## Важное правило: no will after if

В First Conditional в части с **if** обычно не используем **will**.

- Неверно: If I **will see** him, I will tell him.
- Правильно: If I **see** him, I will tell him.

Хотя смысл будущий, грамматически после **if** стоит **Present Simple**.

## Когда использовать

### 1. Возможная ситуация в будущем

- If I get paid tomorrow, I will buy a new phone.
- If they invite us, we will come.

### 2. Предупреждения

- If you touch that wire, you will get an electric shock.
- If you don’t hurry, you will miss the bus.

### 3. Обещания и предложения

- If you need help, I will explain it again.
- If I finish early, I will cook dinner.

## Другие варианты в главной части

Вместо **will** можно использовать модальные глаголы или повелительное наклонение.

### Modal verbs

- If you feel tired, you should rest.
- If it rains, we can stay inside.
- If he calls, you must tell me.

### Imperative

- If you see Anna, tell her to call me.
- If you are hungry, eat something.

## Запятая

Если предложение начинается с **if**, после if-части обычно ставится запятая.

- If I see him, I will tell him.

Если **if** стоит во второй части, запятая обычно не нужна.

- I will tell him if I see him.

## First Conditional vs Zero Conditional

**Zero Conditional** говорит об общем факте или регулярном результате.

- If you heat ice, it melts. — всегда так.

**First Conditional** говорит о конкретной возможной ситуации в будущем.

- If it is cold tomorrow, I will wear a coat. — возможно завтра.

## Частые ошибки

### Ошибка 1: will в if-части

- Неверно: If it **will rain**, we will stay home.
- Правильно: If it **rains**, we will stay home.

### Ошибка 2: забыть -s в Present Simple

- Неверно: If she **come** early, we will start.
- Правильно: If she **comes** early, we will start.

### Ошибка 3: использовать Future Simple в обеих частях

- Неверно: If I **will have** time, I **will help** you.
- Правильно: If I **have** time, I **will help** you.

## Мини-практика

Исправь ошибки:

1. If I will be free tomorrow, I will visit you.
2. If she comes late, we will start without her.
3. We will go outside if it won’t rain.
4. If he doesn’t study, he will fail the test.
5. If you will need help, call me.
